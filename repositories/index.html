Every public HardFOC repository, with its topics, documentation and latest release; type to filter, or pick a topic.

Products¶

Application firmware, one repository per board.

HardFOC Vortex V1 motor controller application firmware (ESP32 / ESP-IDF).

Repository

Core libraries¶

The shared platform every board builds on.

hf-core¶

HardFOC core platform: aggregates hf-core-drivers and hf-core-utils (handlers, RTOS utilities, CANopen, driver integration) for all HardFOC boards.

Repository · Documentation

hf-core-drivers¶

HardFOC core drivers: collection of internal (ESP-IDF interface, pin config) and external hardware-agnostic device drivers as submodules.

Repository · Documentation

hf-core-utils¶

HardFOC core utilities: general utilities, RTOS wrapper and CANopen helpers as submodules.

Repository

hf-internal-interface-wrap¶

HardFOC internal interface layer: hardware-agnostic C++ peripheral base classes (GPIO, ADC, I2C, SPI, UART, CAN, PWM, NVS, timers, ...) with ESP32 / ESP-IDF implementations and STM32 and host ports.

Repository · Documentation

hf-pincfg¶

HardFOC pin configuration: compile-time functional pin definitions and per-board pin maps (Vortex V1, Flux V1).

Repository · Documentation

hf-utils-canopen¶

HardFOC CANopen utilities: self-contained C++ builders for NMT and expedited SDO frames plus CiA 402 drive-control helpers.

Repository

hf-utils-general¶

HardFOC general utilities: header-only C++17 helpers (PID, filters, curve fitting, circular buffers, variable monitors, CRC) with no RTOS or platform dependencies.

Repository

hf-utils-rtos-wrap¶

HardFOC RTOS wrapper: hardware-agnostic C++ abstraction over FreeRTOS primitives (threads, mutexes, queues, timers).

Repository · Documentation

Board HALs¶

One object per board, one manager per board function.

hf-hal-flux-v1¶

HardFOC hardware abstraction layer for the Flux V1 valve-controller board (ESP32 / ESP-IDF), built on hf-core.

Repository · Documentation

hf-hal-vortex-v1¶

HardFOC hardware abstraction layer for the Vortex V1 motor controller board (ESP32 / ESP-IDF), built on hf-core.

Repository · Documentation
